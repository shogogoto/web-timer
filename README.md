# セルフホスト学習タイマー

集中して取り組んだ時間を記録する、小さなセルフホストWebタイマーです。

個人の勉強・読書・作業用としても、家族や小さなグループで共有するタイマーとしても利用できます。業務用タイムトラッカーのような案件管理や請求機能は持たず、カウントダウンと実際に取り組んだ時間の記録に集中しています。

v0.1の主な機能:

- 15分・25分・40分・60分のプリセットと5分単位の調整
- 開始、一時停止、再開、途中終了
- 実行中にタブやブラウザを閉じた場合の自動一時停止
- 終了音とブラウザ通知
- バックグラウンドでも受け取れるWeb Push通知
- 実際に取り組んだ時間の保存
- 利用者本人の今日・今週の合計表示
- 管理者によるアカウント作成と利用者別集計

## 起動

```bash
cp .env.example .env
# .env のパスワードと秘密鍵を必ず変更する
docker compose up --build
```

`http://localhost:8000/login` を開きます。初回起動時に `.env` の管理者アカウントが作成されます。管理画面からタイマーを使う利用者アカウントを追加してください。個人利用の場合は、自分用の利用者アカウントを1つ作成します。

本番でHTTPSのリバースプロキシ配下に置く場合は `COOKIE_SECURE=true` にしてください。通知APIはlocalhost以外ではHTTPSが必要です。終了音はブラウザ内で生成します。画面に必要なAlpine.jsはアプリから配信するため、CDNへの接続は必要ありません。

Web PushにはHTTPSが必要です。初回起動時にVAPID秘密鍵が`data/vapid_private.pem`へ自動生成されます。このファイルを失うと既存のPush購読が使えなくなるため、`timer.db`と一緒にバックアップしてください。通知の連絡先は`.env`の`VAPID_SUBJECT`で設定できます。

SQLiteデータは `./data/timer.db` に保存されます。このファイルを停止中にコピーすればバックアップできます。

終了通知などを確認する場合は、`.env`で`ALLOW_SHORT_TIMERS=true`にすると「1秒（デバッグ）」プリセットが表示されます。通常運用では`false`にしてください。
